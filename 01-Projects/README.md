# 01-Projects

入职华东之后的工作按「主线 / 子线」组织。主线是当前交付项目；子线是了解公司和医药行业的学习任务。

## 主线

- [[写作辅助/README|写作辅助 / 方案撰写]]：M11 方案撰写、竞品分析、摘要抽取与写作辅助。
- [[华东医药研发管线管理系统/README|华东医药研发管线管理系统]]：一期管线系统的 PRD、蓝图、接口和原型。

代码仓库在桌面 `workspace/int-service-study-management`。

## 子线

子线统一收在 [[华东医药入职学习/00-首页|华东医药入职学习]]，每一项当作一个任务推进：

- 公司与行业理解（业务板块、系统、术语、90 天计划）
- [[研发流程/README|研发流程 SOP]]
- [[CSR临床研究报告知识库/00-老板汇报提纲|CSR 临床研究报告]]
- [[工作文档/README|工作文档]]

适应症公开源采集代码在桌面 `workspace/indication-intel`，笔记仍留在入职学习的 CSR 知识库里。

## 使用规则

- 项目必须有目标、截止日期和成功标准。
- 每份交付按 [[工作产出飞轮/README|工作产出飞轮]] 拆资产并登记 [[产出台账]]；下次开工先看 [[可复用资产索引]]。
- 项目完成后，把可复用经验沉淀回对应领域，再把项目移入 `04-Archives`。
- 前公司途虎资料已归档，不放在本目录。
