# M. 成本估算与预算

> 本文档记录 M11 方案生成 Copilot 项目的成本构成、估算方法和预算建议。
> 定稿日期：2026-08-20

---

## 1. 估算假设

| 假设项 | 取值 | 说明 |
|---|---|---|
| 阶段一处理方案数 | 30 份/月 | 3-5 份真实摘要 + 公开/重构摘要 |
| 每份方案平均章节数 | 1 章（阶段一） | 只跑 1.1.1 |
| 每章 LLM 调用次数 | 5 次 | 提取 1 次 + 生成 1 次 + 一致性检查 2 次 + 评审 1 次 |
| 每次调用平均 token 数 | 8k 输入 / 2k 输出 | 医学文本长，Prompt 带示例 |
| 阶段一模型 | Claude Sonnet 4.6 / GPT-5.4 | 质量与成本平衡 |
| 部署环境 | Docker Compose 单机 | 阶段一不扩容 |
| 团队规模 | 2 后端 + 1 前端 + 1 医学顾问（兼职） | 阶段一 |

## 2. LLM 调用成本（阶段一，月度）

|---|---|---|
| Claude Sonnet 4.6 | ~$3 | ~$15 |
| Claude Opus 4.6 | ~$15 | ~$75 |
| GPT-5.4 | ~$2 | ~$10 |
| GPT-5.5 | 略高于 5.4 | 略高于 5.4 |
| Qwen2.5-1M | ~$0.5-1 | ~$2-4 |
| DeepSeek Medical | ~$0.5-1 | ~$2-4 |

### 2.2 月度计算

| 项目 | 计算 |
|---|---|
| 输入 token | 30 份 × 5 次 × 8k = 1,200k |
| 输出 token | 30 份 × 5 次 × 2k = 300k |

| 模型 | 月度成本 |
|---|---|
| Claude Sonnet 4.6 | **$8.1** |
| Claude Opus 4.6 | **$40.5** |
| GPT-5.4 | **$5.4** |
| Qwen2.5-1M | **~$1.5** |

### 2.3 阶段一合计（2 个月）

| 模型 | 2 个月 |
|---|---|
| Claude/GPT | **~$11-16** |
| 国产模型 | **~$3-6** |

> 阶段一 LLM 成本几乎可以忽略。真正的成本是 **人和时间**。

## 6. 全周期（6 个月）预算预估

| 阶段 | 时间 | LLM 成本 | 基础设施 | 顾问费用 | 主要特征 |
|---|---|---|---|---|---|
| 阶段一 | 1-2 月 | ¥200 | ¥620 | ¥25-50k | 1 个章节跑通 |

---

## 7. 阶段二/三 LLM 成本上升点

| 因素 | 影响 |
|---|---|
| 章节数从 1 → 14 | LLM 调用量增加 10-14 倍 |
| 每章质量评审次数增加 | 反馈闭环需要多次生成对比 |
| 黄金样本回归测试 | 每次 Skill 升级跑全量样本 |
| 多模型 bake-off | 同一份输入跑 2-3 个模型 |
| 长上下文需求 | 跨章节一致性检查需要更大上下文窗口 |

阶段二月度 LLM 成本可能达到 **¥500-1500/月**，阶段三 **¥1500-4000/月**。

---

## 8. 成本控制策略

| 策略 | 具体做法 | 节省效果 |
|---|---|---|
| **按泳道选模型** | 提取用便宜模型，生成用贵模型 | 30-50% |
| **缓存重复调用** | 相同摘要的元数据提取结果缓存 | 10-20% |
| **占位符减少无效生成** | 不确定内容不生成，留 `<输入...>` | 减少返工 |
| **黄金样本精选** | 回归测试不用全量，用 10-20 个代表性样本 | 50%+ |
| **医学顾问时间集中使用** | 批量评审，避免碎片化 | 降低单位成本 |
| **先用国产/便宜模型跑通** | 等技术稳定后再切高质量模型 | 阶段一可省 70% |

## 9. 风险预算

| 风险 | 预算预留 | 说明 |
|---|---|---|
| 数据合规要求私有化模型 | +¥5-20k | GPU 或本地部署 |
| 生成质量不达标需要更多迭代 | +¥30-50k 顾问费 | 多轮 Skill 优化 |
| 真实样本获取困难 | +¥10-20k | 可能需要购买/脱敏处理 |
| 云服务商价格变动 | +10% | 按月度弹性 |

建议阶段一预留 **20-30%** 风险预算。
