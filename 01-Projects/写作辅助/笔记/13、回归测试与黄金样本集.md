# 13. 回归测试与黄金样本集

> 本文档记录 M11 方案生成 Copilot 的黄金样本集构建、回归测试流程和 Skill 升级决策机制。
> 定稿日期：2026-08-20

---

## 1. 目标

- 建立可重复的质量基准
- 每次 Skill 升级都能量化评估影响
- 防止 Skill 退化
- 为模型 bake-off 提供固定测试集

---

## 2. 黄金样本集

### 2.1 样本选择标准

| 标准 | 说明 |
|---|---|
| **代表性** | 覆盖不同适应症、分期、设计类型 |
| **稳定性** | 输入内容不频繁变更 |
| **可评估** | 有明确的期望输出或评分标准 |
| **规模可控** | 阶段一 3-5 个，阶段二 10-20 个，阶段三 30+ |

### 2.2 阶段一黄金样本

| 样本 ID | 适应症 | 分期 | 设计类型 | 来源 |
|---|---|---|---|---|
| GOLD-001 | 中重度斑块型银屑病 | II 期 | 随机、双盲、安慰剂对照 | 虚构 |
| GOLD-002 | 非小细胞肺癌 | III 期 | 随机、开放 | 公开摘要 |
| GOLD-003 | 类风湿关节炎 | II 期 | 随机、双盲 | 公开摘要 |
| GOLD-004 | 特应性皮炎 | III 期 | 随机、双盲 | 公开摘要 |
| GOLD-005 | 多发性硬化症 | III 期 | 随机、双盲、阳性对照 | 重构 |

### 2.3 样本结构

```
golden_samples/

│   ├── expected_metadata.json
```

## 3. 回归测试流程

### 3.1 触发时机

- Skill YAML 变更
- Prompt 模板变更
- 模型切换
- 元数据提取规则变更
- 每周定期运行

### 3.2 测试流程

```python
class RegressionTest:
    def run(self, skill_version: str, model: str) -> RegressionReport:
        results = []
        for sample in self.golden_samples:
            # 1. 解析
            doc = self.parser.parse(sample.synopsis)
            
            # 2. 提取元数据
            metadata = self.extractor.extract(doc, sample.id)
            
            # 3. 生成章节
            content = self.generator.generate(
                chapter_id="1.1.1",
                skill_version=skill_version,
                metadata=metadata,
                task_id=sample.id,
            )
            
            # 4. 评估
            score = self.evaluator.evaluate(
                content, sample.expected_chapter_1_1_1
            )
            
            results.append(score)
        
        return RegressionReport(results=results)
```

## 4. 评估指标

### 4.1 自动指标

| 指标 | 说明 | 阶段一目标 |
|---|---|---|
| **字段完整率** | required_metadata 全部有值 | 100% |
| **事实准确率** | 生成内容与输入一致 | ≥ 95% |
| **结构完整率** | M11 章节要素齐全 | 100% |
| **占位符正确率** | 不确定处正确标注 | ≥ 95% |
| **BLEU/ROUGE** | 与参考文本的相似度 | 参考 |
| **LLM-as-judge** | 模型打分 | 辅助 |

### 4.2 人工指标

| 指标 | 说明 | 阶段一目标 |
|---|---|---|
| **修改比例** | 医学专家修改字数 / 总字数 | ≤ 40% |
| **事实错误数** | 明显事实错误数量 | 0 |
| **可用度评分** | 1-5 分 | ≥ 3 |

## 6. Skill 升级决策

### 6.1 升级条件

| 条件 | 决策 |
|---|---|
| 新版本通过率 ≥ 旧版本 + 无事实错误 | 升级 |
| 新版本通过率提升但有个别样本下降 | 人工审核后决定 |
| 新版本通过率下降 | 不升级，回退 |
| 新版本引入事实错误 | 禁止升级 |

### 6.2 A/B 测试

```python
{
  "task_id": "task-001",
  "skill_versions": {
    "1.1.1": "1.2.0"    # 新版本
  }
}
```

生成结果与旧版本对比，由医学专家评分。

## 7. CI/CD 集成

```yaml
# .github/workflows/regression.yml
name: Regression Test
on:
  push:
    paths:
      - "skills/**/*.yaml"
      - "src/generator/**"
      - "src/extractor/**"

jobs:
  regression:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run regression tests
        run: pytest tests/regression/ -v
      - name: Upload report
        uses: actions/upload-artifact@v4
        with:
          name: regression-report
          path: reports/regression_report.json
```
