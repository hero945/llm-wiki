# 8. 生成模块设计

> 本文档记录 M11 方案生成 Copilot 的 Generator 模块设计，包括 Skill DSL、Prompt 构建、LLM 调用和输出生成。
> 定稿日期：2026-08-20

---

## 1. 模块定位

Generator 模块负责把**确认后的元数据** + **Skill 规则**组合成 Prompt，调用 LLM 生成 M11 章节内容，并输出结构化的 `ChapterContent`。

阶段一聚焦 **第 1.1.1 章「主要和次要目的及估计目标」**。

---

## 2. 输入 / 输出

### 2.1 输入

| 输入 | 类型 | 说明 |
|---|---|---|
| `chapter_id` | str | 章节编号，如 "1.1.1" |
| `skill_version` | str | Skill 版本，如 "1.0.0" |
| `metadata` | dict | 经确认后的结构化元数据 |
| `task_id` | str | 任务 ID，用于日志和追踪 |
| `context` | dict | 可选上下文，如历史方案示例 |

### 2.2 输出：ChapterContent

```python
from pydantic import BaseModel
from typing import Any
from datetime import datetime

class Issue(BaseModel):
    issue_id: str
    severity: str           # error / warning / info
    field: str | None
    message: str
    suggestion: str | None

class GenerationMeta(BaseModel):
    model: str
    prompt_tokens: int
    completion_tokens: int
    latency_ms: int
    generated_at: datetime

class ChapterContent(BaseModel):
    chapter_id: str
    chapter_title: str
    content: str            # Markdown 格式正文
    issues: list[Issue]
    generation_meta: GenerationMeta
```

## 3. Skill DSL 设计

Skill 用 YAML 定义，是医学规则的可维护载体。

```yaml
skill:
  chapter_id: "1.1.1"
  chapter_title: "主要和次要目的及估计目标"
  version: "1.0.0"
  owner: "医学写作团队"

  required_metadata:
    - trial_identification.indication
    - objectives.primary
    - objectives.secondary
    - objectives.exploratory
    - interventions
    - population.diagnosis

  writing_rules:
    - "先写目的句，使用'本试验旨在评估...'句式"
    - "主要目的按'人群 + 干预 + 终点'三段式描述"
    - "估计目标按 ICH E9(R1) 五属性描述"
    - "次要目的分段列出，每段一个目的"
    - "探索性目的放在最后，单独成段"

  forbidden_patterns:
    - "不得使用'证明'，应使用'评估'"
    - "不得遗漏伴发事件策略"
    - "不得对未提供的次要终点进行编造"

  examples:
    - example_id: "pso_phase2_001"
      content: |
        3.1 主要和次要目的及估计目标
        本试验旨在评价 X 药 60 mg 和 120 mg 治疗中重度斑块型银屑病患者的有效性。
        
        主要估计目标...
      score: 0.95

  consistency_rules:
    - "主要终点必须与 endpoints.primary 一致"
    - "估计目标中的治疗条件必须与 interventions 一致"

  prompt_template: |
    你是一名医学写作专家，正在撰写 ICH M11 方案的第 {{ skill.chapter_id }} 章「{{ skill.chapter_title }}」。

    ## 已知事实
    {{ metadata | to_yaml }}

    ## 写作规则
    {% for rule in skill.writing_rules %}
    - {{ rule }}
    {% endfor %}

    ## 禁止项
    {% for pattern in skill.forbidden_patterns %}
    - {{ pattern }}
    {% endfor %}

    ## 示例
    {% for ex in skill.examples %}
    {{ ex.content }}
    {% endfor %}

    ## 要求
    1. 只输出第 {{ skill.chapter_id }} 章的内容
    2. 使用中文医学写作规范
    3. 对不确定的信息，使用 `<输入...>` 占位符标注，不要编造
    4. 主要目的必须配一个主要估计目标（五属性）
    5. 返回格式为 Markdown
```

## 4. 核心类设计

### 4.1 Skill 模型

```python
class Skill(BaseModel):
    chapter_id: str
    chapter_title: str
    version: str
    owner: str
    required_metadata: list[str]
    writing_rules: list[str]
    forbidden_patterns: list[str]
    examples: list[dict]
    consistency_rules: list[str]
    prompt_template: str
```

### 4.2 SkillLoader

```python
class SkillLoader:
    @staticmethod
    def load(chapter_id: str, version: str) -> Skill:
        path = f"skills/chapter_{chapter_id.replace('.', '_')}/{version}.yaml"
        with open(path) as f:
            data = yaml.safe_load(f)
        return Skill(**data["skill"])
```

### 4.3 PromptBuilder

```python
from jinja2 import Environment, BaseLoader

class PromptBuilder:
    def __init__(self):
        self.env = Environment(loader=BaseLoader())
        self.env.filters["to_yaml"] = lambda x: yaml.safe_dump(x, allow_unicode=True)

    def build(self, skill: Skill, metadata: dict, context: dict | None = None) -> str:
        template = self.env.from_string(skill.prompt_template)
        return template.render(
            skill=skill,
            metadata=metadata,
            context=context or {},
        )
```

### 4.4 ChapterGenerator

```python
class ChapterGenerator:
    def __init__(self, gateway: LLMGateway):
        self.gateway = gateway

    def generate(
        self,
        chapter_id: str,
        skill_version: str,
        metadata: dict,
        task_id: str,
    ) -> ChapterContent:
        # 1. 加载 Skill
        skill = SkillLoader.load(chapter_id, skill_version)

        # 2. 校验 required_metadata
        missing = self._check_required_metadata(skill, metadata)
        if missing:
            return ChapterContent(
                chapter_id=chapter_id,
                chapter_title=skill.chapter_title,
                content="",
                issues=[Issue(...)],
                generation_meta=None,
            )

        # 3. 渲染 Prompt
        prompt = PromptBuilder.build(skill, metadata)

        # 4. 调用 LLM
        result = self.gateway.generate(
            chapter_id=chapter_id,
            task_id=task_id,
            skill_version=skill_version,
            prompt=prompt,
            metadata=metadata,
        )

        # 5. 后处理
        content = self._post_process(result.text)
        issues = self._scan_placeholders(content)

        return ChapterContent(
            chapter_id=chapter_id,
            chapter_title=skill.chapter_title,
            content=content,
            issues=issues,
            generation_meta=result.meta,
        )
```

## 5. LLM 网关调用

Generator 通过 LLM Gateway 的 `generate()` 泳道调用：

```python
class LLMGateway:
    def generate(
        self,
        chapter_id: str,
        task_id: str,
        skill_version: str,
        prompt: str,
        metadata: dict,
    ) -> GenerationResult:
        ...
```

调用参数：
- `model`: 默认 Claude Sonnet 4.6
- `temperature`: 0.1-0.3（生成任务低随机性）
- `max_tokens`: 根据章节长度设定
- `metadata`: 用于日志关联

## 6. 后处理

### 6.1 内容清洗

- 去除 Markdown 代码块标记（如果模型误加）
- 统一标题层级
- 规范换行和段落间距

### 6.2 占位符扫描

```python
def _scan_placeholders(self, content: str) -> list[Issue]:
    import re
    pattern = r"<输入[^>]*>"
    matches = re.finditer(pattern, content)
    return [
        Issue(
            issue_id=f"placeholder-{i}",
            severity="warning",
            field=None,
            message=f"发现占位符：{m.group()}",
            suggestion="请补充对应信息后重新生成",
        )
        for i, m in enumerate(matches)
    ]
```

## 7. Issue 分级

| severity | 定义 | 示例 |
|---|---|---|
| **error** |  blocker，必须解决才能继续 | required_metadata 缺失 |
| **warning** | 建议处理，不阻塞 | 存在占位符 |
| **info** | 提示信息 | 使用了示例中的句式 |

## 8. 与其他模块的关系

```
ConfirmedMetadata
   ↓
Skill Loader → Skill
   ↓
Prompt Builder → Prompt
   ↓
LLM Gateway → LLM Response
   ↓
ChapterGenerator → ChapterContent
   ↓
Consistency Checker → 新增/更新 Issue
   ↓
Word Renderer → Word 初稿
```
