# 解析模块设计（Parser）

> 本文档记录「摘要/IB/模板」解析模块的详细设计。
> 定稿日期：2026-08-19

---

## 1. 目标

把输入文件转换为系统内部统一的结构化文档对象，屏蔽底层格式差异，为下游的元数据提取、章节生成提供一致的输入。

---

## 2. 输入 / 输出

### 2.1 输入

| 文件类型 | 阶段一支持 | 说明 |
| --- | --- | --- |
| `.docx` | ✅ 主路径 | 方案摘要、研究者手册（IB）、M11 模板 |
| `.pdf` | ❌ 阶段一不做 | 真实样本暂以 docx 为主，PDF 后续扩展 |
| `.txt/.md` | ✅ 测试用 | 简化输入，便于单元测试和快速验证 |

### 2.2 输出：Document 对象

```python
class Document(BaseModel):
    file_type: Literal["docx", "txt"]
    file_name: str
    sections: List[Section]
    tables: List[Table]
    images: List[Image]
    raw_text: str
    metadata: dict

class Section(BaseModel):
    heading_level: int      # 0=正文, 1=一级标题, 2=二级标题...
    heading_text: str       # 标题内容，正文为空
    paragraphs: List[str]   # 该 section 下的段落

class Table(BaseModel):
    caption: str | None
    rows: List[List[str]]

class Image(BaseModel):
    image_type: str         # picture / chart
    alt_text: str | None    # 图片附近文本或 OCR 结果
    raw_bytes: bytes | None # 原始图像数据
    position_hint: str      # 所在段落/章节提示
```

## 3. 核心设计：适配器模式

```
        .docx  ──→  DocxParser ──┐
        .txt   ──→  TextParser ──┼──→  Document 对象
        .pdf   ──→  PdfParser   ──┘  （阶段二）
```

业务模块只依赖 `Document`，不依赖具体文件格式。

### 3.1 接口定义

```python
from abc import ABC, abstractmethod

class BaseParser(ABC):
    @abstractmethod
    def parse(self, file_path: str) -> Document:
        """将文件解析为统一的 Document 对象"""
        pass

    @abstractmethod
    def supports(self, file_path: str) -> bool:
        """判断是否支持该文件类型"""
        pass

class ParseError(Exception):
    """解析失败时抛出"""
    pass

def get_parser(file_path: str) -> BaseParser:
    """根据文件后缀选择解析器"""
    suffix = Path(file_path).suffix.lower()
    parsers = {
        ".docx": DocxParser(),
        ".txt": TextParser(),
        ".md": TextParser(),
    }
    if suffix not in parsers:
        raise ParseError(f"不支持的文件类型: {suffix}")
    return parsers[suffix]
```

## 4. 关键实现

### 4.1 DocxParser

使用 `python-docx` 读取 `.docx` 文件。

#### 4.1.1 段落处理

按段落样式识别标题层级：

| 样式名 | heading_level |
| --- | --- |
| `Heading 1` / `标题 1` | 1 |
| `Heading 2` / `标题 2` | 2 |
| `Heading 3` / `标题 3` | 3 |
| 普通段落 / `Normal` / `正文` | 0 |

#### 4.1.2 算法

```python
from docx import Document as DocxDocument
from pydantic import BaseModel
from typing import List
import re

class Section(BaseModel):
    heading_level: int
    heading_text: str
    paragraphs: List[str]

class DocxParser(BaseParser):
    def parse(self, file_path: str) -> Document:
        doc = DocxDocument(file_path)
        sections = []
        current = Section(heading_level=0, heading_text="", paragraphs=[])
        
        for para in doc.paragraphs:
            text = para.text.strip()
            if not text:
                continue
            
            level = self._detect_heading_level(para)
            if level > 0:
                # 保存上一 section
                if current.paragraphs or current.heading_text:
                    sections.append(current)
                current = Section(heading_level=level, heading_text=text, paragraphs=[])
            else:
                current.paragraphs.append(text)
        
        # 收尾
        if current.paragraphs or current.heading_text:
            sections.append(current)
        
        return Document(
            file_type="docx",
            file_name=file_path,
            sections=sections,
            tables=self._parse_tables(doc),
            images=self._parse_images(doc),
            raw_text="\n".join(p.text for p in doc.paragraphs if p.text.strip()),
            metadata={"paragraph_count": len(doc.paragraphs)},
        )
    
    def _detect_heading_level(self, para) -> int:
        style_name = para.style.name if para.style else ""
        
        # 按样式名判断
        for i in range(1, 4):
            if f"Heading {i}" in style_name or f"标题 {i}" in style_name:
                return i
        
        return 0
```

### 4.2 表格解析

```python
def _parse_tables(self, doc: DocxDocument) -> List[Table]:
    tables = []
    for table in doc.tables:
        rows = []
        for row in table.rows:
            rows.append([cell.text.strip() for cell in row.cells])
        tables.append(Table(caption=None, rows=rows))
    return tables
```

### 4.3 图片 / 图表解析

`python-docx` 本身对图片支持有限，需要直接解析 Word XML（`document.xml`）。

#### 4.3.1 图片提取

```python
from docx.oxml import parse_xml

def _parse_images(self, doc: DocxDocument) -> List[Image]:
    images = []
    rels = doc.part.rels
    
    for rel in rels.values():
        if "image" in rel.reltype:
            image_part = rel.target_part
            image_bytes = image_part.blob
            images.append(Image(
                image_type="picture",
                alt_text=None,
                raw_bytes=image_bytes,
                position_hint="待补充：需要结合段落位置",
            ))
    return images
```

#### 4.3.2 图表提取

Word 中的图表通常是 **Office Open XML 图表**（`chart*.xml`），需要：

1. 解压 docx 文件
2. 遍历 `word/charts/` 目录
3. 提取图表数据为表格形式

实现方式：

```python
import zipfile
from xml.etree import ElementTree as ET

def _parse_charts(self, file_path: str) -> List[Table]:
    charts = []
    ns = {
        "c": "http://schemas.openxmlformats.org/drawingml/2006/chart",
    }
    
    with zipfile.ZipFile(file_path) as zf:
        chart_files = [n for n in zf.namelist() if n.startswith("word/charts/chart")]
        for chart_file in chart_files:
            xml = zf.read(chart_file)
            root = ET.fromstring(xml)
            
            # 提取系列名称和数据点
            # 这里需要按图表类型（柱状图、折线图等）分别处理
            series_data = self._extract_chart_series(root, ns)
            charts.append(Table(caption=f"chart_{chart_file}", rows=series_data))
    
    return charts
```

**说明**：图表解析复杂度较高，阶段一可以先实现基础提取（系列标签 + 数值），复杂的图表类型后续迭代。

### 4.4 TextParser

测试用，按空行分段：

```python
class TextParser(BaseParser):
    def parse(self, file_path: str) -> Document:
        text = Path(file_path).read_text(encoding="utf-8")
        paragraphs = [p.strip() for p in text.split("\n\n") if p.strip()]
        
        return Document(
            file_type="txt",
            file_name=file_path,
            sections=[Section(heading_level=0, heading_text="", paragraphs=paragraphs)],
            tables=[],
            images=[],
            raw_text=text,
            metadata={},
        )
```

## 5. 边界情况处理

| 情况 | 处理策略 |
| --- | --- |
| 样式名不规范 | 阶段一只按标准样式名判断，不处理非标准样式；后续增加编号模式辅助判断 |
| 文件损坏或加密 | 捕获异常，抛出 `ParseError`，外层 job 标记 `failed` |
| 表格为空或格式异常 | 返回空表格，记录 warning |
| 图片无法解析 | 返回 `raw_bytes=None`，保留 `alt_text` 或位置提示 |
| 超大文件 | 设置段落数上限，超出时截断并记录 warning |
| 中文字符 | `python-docx` 原生支持，无需额外编码处理 |

## 6. 与其他模块的关系

```
输入文件
   ↓
Parser → Document 对象
   ↓
Extractor（元数据提取）
   ↓
Metadata 对象
```

- `Document.sections` 和 `Document.raw_text` 提供给 `Extractor`
- `Document.tables` 在阶段二用于 IB 中的表格信息提取
- `Document.images` 暂不进入阶段一生成链路，仅保存备用
