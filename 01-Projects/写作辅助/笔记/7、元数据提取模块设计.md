# 元数据提取模块设计（Extractor）

> 本文档记录从 Document 提取结构化元数据的设计。
> 定稿日期：2026-08-19

---

## 1. 目标

从 `Document` 中自动提取撰写 M11 方案所需的结构化信息，并为每个字段标注可信度，决定该字段直接采用、LLM 增强还是人工确认。

---

## 2. 输入 / 输出

### 2.1 输入

`Document` 对象（来自 [[6、解析模块设计]]）：

- `raw_text`：全文纯文本
- `sections`：按标题切分的段落组
- `tables`：表格数据

### 2.2 输出：Metadata 对象

```python
from typing import Any
from pydantic import BaseModel

class MetadataField(BaseModel):
    field: str              # 字段名
    value: Any              # 提取值
    confidence: float       # 0.0 ~ 1.0
    source: str             # "rule" / "llm" / "rule+llm" / "human" / "unknown"
    raw_text: str | None    # 原始文本片段
    need_confirm: bool      # 是否需要人工确认

class Metadata(BaseModel):
    task_id: str
    fields: dict[str, MetadataField]   # key: field_name
    missing_fields: list[str]          # 缺失字段列表
    extracted_at: datetime
```

---

## 3. 核心设计：双引擎 + 融合层

```
Document
   ↓
┌─────────────┐     ┌─────────────┐
│  规则引擎    │     │  LLM 增强   │
│  (Rule)     │     │  (LLM)      │
└──────┬──────┘     └──────┬──────┘
       │                   │
       └───────┬───────────┘
               ↓
          融合层 (Fusion)
               ↓
        Metadata 对象
               ↓
    ├─ 高置信度 (≥0.9) → 直接用
    ├─ 中置信度 (0.7~0.9) → 人工确认后使用
    └─ 低置信度 (<0.7) → 必须人工填写
```

### 3.1 分工原则

| 字段类型 | 例子 | 负责方 | 原因 |
| --- | --- | --- | --- |
| 结构稳定字段 | 样本量、分期、设计类型、盲法 | 规则引擎 | 模式固定，可解释、可审计 |
| 语义复杂字段 | 估计目标五属性、给药频率、终点评估方法 | LLM | 描述多样，需要医学语义理解 |
| 两者冲突字段 | 主要目的、入排标准 | 规则 + LLM 融合 | 规则初提，LLM 校验/补充 |

#### 4.1.2 规则引擎接口

```python
from pydantic import BaseModel
from typing import Literal

class Pattern(BaseModel):
    type: Literal["regex", "keyword"]
    # regex 专用
    pattern: str | None = None
    group: int | None = 1
    # keyword 专用
    values: list[str] | None = None
    # 通用
    parser: Literal["single", "bullet_list", "int", "float"] = "single"

class ExtractionRule(BaseModel):
    field: str
    description: str
    value_type: Literal["string", "int", "float", "list", "dict", "bool"]
    patterns: list[Pattern]
    confidence: float

class RuleSet(BaseModel):
    version: str
    description: str
    rules: list[ExtractionRule]

class RuleEngine:
    def __init__(self, rule_set: RuleSet):
        self.rule_set = rule_set

    def extract(self, document: Document) -> dict[str, MetadataField]:
        """对 Document 应用规则集，返回字段提取结果"""
        results = {}
        for rule in self.rule_set.rules:
            value, raw_text = self._apply_rule(document.raw_text, rule)
            confidence = rule.confidence if value is not None else 0.0
            results[rule.field] = MetadataField(
                field=rule.field,
                value=value,
                confidence=confidence,
                source="rule",
                raw_text=raw_text,
                need_confirm=confidence < 0.9,
            )
        return results

    def _apply_rule(self, text: str, rule: ExtractionRule) -> tuple[Any, str | None]:
        for pattern in rule.patterns:
            if pattern.type == "regex" and pattern.pattern:
                match = re.search(pattern.pattern, text)
                if match:
                    raw = match.group(0)
                    val = match.group(pattern.group or 1)
                    return self._parse_value(val, pattern.parser, rule.value_type), raw
            elif pattern.type == "keyword" and pattern.values:
                for kw in pattern.values:
                    if kw in text:
                        return kw, kw
        return None, None

    def _parse_value(self, raw: str, parser: str, value_type: str) -> Any:
        if value_type == "int":
            return int(raw)
        if value_type == "float":
            return float(raw)
        if parser == "bullet_list":
            return [line.strip("•-* \\t") for line in raw.split("\n") if line.strip()]
        return raw.strip()
```

### 4.2 LLM 增强

#### 4.2.1 提取策略

阶段一采用 **单次 Prompt 提取所有字段**，Prompt 中注入规则已提取的结果作为参考。

#### 4.2.2 LLM 提取接口

```python
class LLMExtractor:
    def __init__(self, gateway: LLMGateway):
        self.gateway = gateway

    def enhance(
        self,
        document: Document,
        fields: list[str],
        rule_results: dict[str, MetadataField],
    ) -> dict[str, MetadataField]:
        prompt = self._build_prompt(document.raw_text, fields, rule_results)
        
        response = self.gateway.extract(
            input_text=prompt,
            schema=self._output_schema(fields),
            task_id=document.metadata.get("task_id"),
        )
        
        return self._parse_response(response.data)
```

### 4.3 融合层

```python
class FusionEngine:
    def fuse(
        self,
        rule_results: dict[str, MetadataField],
        llm_results: dict[str, MetadataField],
    ) -> dict[str, MetadataField]:
        fused = {}
        all_fields = set(rule_results.keys()) | set(llm_results.keys())
        
        for field in all_fields:
            rule_val = rule_results.get(field)
            llm_val = llm_results.get(field)
            
            # 规则高置信度：直接采用
            if rule_val and rule_val.confidence >= 0.9:
                fused[field] = rule_val
                continue
            
            # 规则中置信度 + LLM 有值：LLM 校验
            if rule_val and rule_val.confidence >= 0.7 and llm_val and llm_val.value is not None:
                if self._values_equal(rule_val.value, llm_val.value):
                    fused[field] = MetadataField(
                        field=field,
                        value=rule_val.value,
                        confidence=0.95,
                        source="rule+llm",
                        raw_text=rule_val.raw_text,
                        need_confirm=False,
                    )
                else:
                    fused[field] = MetadataField(
                        field=field,
                        value=llm_val.value,
                        confidence=0.75,
                        source="llm",
                        raw_text=llm_val.raw_text,
                        need_confirm=True,
                    )
                continue
            
            # 规则低置信度/未识别，LLM 有值：采用 LLM
            if llm_val and llm_val.value is not None:
                llm_val.need_confirm = llm_val.confidence < 0.9
                fused[field] = llm_val
                continue
            
            # 都未命中：缺失
            fused[field] = MetadataField(
                field=field,
                value=None,
                confidence=0.0,
                source="unknown",
                raw_text=None,
                need_confirm=True,
            )
        
        return fused
    
    def _values_equal(self, a: Any, b: Any) -> bool:
        """简单值比较，支持字符串归一化"""
        if isinstance(a, str) and isinstance(b, str):
            return a.strip().lower() == b.strip().lower()
        return a == b
```

### 4.4 整体流程

```python
class MetadataExtractor:
    def __init__(self, rule_engine: RuleEngine, llm_extractor: LLMExtractor):
        self.rule_engine = rule_engine
        self.llm_extractor = llm_extractor
        self.fusion = FusionEngine()

    def extract(self, document: Document, task_id: str, fields: list[str]) -> Metadata:
        # 1. 规则提取
        rule_results = self.rule_engine.extract(document)
        
        # 2. LLM 增强（只处理未命中或低置信度的字段）
        fields_to_enhance = [
            f for f in fields
            if f not in rule_results or rule_results[f].confidence < 0.9
        ]
        llm_results = self.llm_extractor.enhance(document, fields_to_enhance, rule_results)
        
        # 3. 融合
        fused = self.fusion.fuse(rule_results, llm_results)
        
        # 4. 只保留需要的字段
        final_fields = {f: fused[f] for f in fields if f in fused}
        missing = [f for f, v in final_fields.items() if v.value is None]
        
        return Metadata(
            task_id=task_id,
            fields=final_fields,
            missing_fields=missing,
            extracted_at=datetime.now(),
        )
```

## 6. 置信度与确认策略

| 置信度 | 处理方式 | 下游行为 |
| --- | --- | --- |
| ≥ 0.9 | 高置信度，直接使用 | 进入生成环节 |
| 0.7 ~ 0.9 | 中置信度，建议确认 | 事实确认工作台展示，专家一键确认或修改 |
| < 0.7 | 低置信度，必须人工填写 | 不能为空，必须填值才能继续 |
| value 为 null | 缺失字段 | 标为占位符 `<输入...>` 或强制补充 |

---

## 7. 边界情况

| 情况 | 处理 |
| --- | --- |
| 规则未命中 | confidence=0，交给 LLM；LLM 也未命中则标为缺失 |
| LLM 返回 JSON 格式错误 | 重试 1 次；仍失败则该字段 source="unknown"，need_confirm=True |
| 规则与 LLM 结果冲突 | 默认采用 LLM 结果（confidence 0.75），需要人工确认 |
| 多值字段解析失败 | 保留原始文本，confidence 降低，人工确认 |
| 字段值为空字符串 | 视为 null，标为缺失 |

## 8. 与其他模块的关系

```
Document（解析模块输出）
   ↓
MetadataExtractor
   ↓
Metadata（元数据对象）
   ↓
├─ 高置信度字段 → 直接传给 Generator
└─ 待确认字段 → Confirm 模块（事实确认工作台）
   ↓
ConfirmedMetadata
   ↓
Generator（章节生成）
```
