# 方案摘要 → 全文生成证据映射分析

> 基于 ICH M11 模板结构、十四章节关系图，以及公开临床试验方案摘要提炼。
> 目的：明确从摘要中提取哪些内容，可以支撑后续 LLM 生成各章节。

---

## 一、分析框架

### 1.1 摘要的本质作用

方案摘要是一份试验的"浓缩版方案"，通常包含：
- 试验背景与 rationale
- 试验目的与设计
- 人群与干预
- 终点与统计
- 安全与伦理

但摘要不是为"逐章扩写"而写的，很多支撑章节写作的**细节和上下文**在摘要中并不完整。因此需要：
1. **提取显式信息**：摘要中直接写明的
2. **推断隐含信息**：基于医学常识和上下文推断
3. **识别缺失信息**：需要交互补充的

### 1.2 证据类型分类

| 证据类型 | 说明 | 示例 |
|----------|------|------|
| **事实型证据** | 可直接抽取的确定信息 | 样本量 180、药物剂量 60mg、PASI75 应答率 |
| **描述型证据** | 需要保留原文表述的段落 | 疾病背景、入选标准描述、风险缓解策略 |
| **关系型证据** | 涉及多章节关联的信息 | 主要终点 ↔ 统计方法、干预方案 ↔ 评估程序 |
| **推理型证据** | 需要 LLM 理解医学语义 | 给药方案逻辑、估计目标五属性、设计依据 |

### 1.3 提取方式标注

- **R**：适合规则提取（正则、关键词、模式匹配）
- **L**：适合 LLM 提取/理解（语义复杂、描述多样）
- **R+L**：规则初提 + LLM 校验/规范化

## 二、逐章证据映射

### 第 1 章：方案概要

**本章定位**：全文摘要，浓缩展示试验关键信息。

**M11 要求内容**：
- 1.1 方案摘要
  - 1.1.1 主要和次要目的及估计目标
  - 1.1.2 总体设计
- 1.2 试验示意图
- 1.3 活动时间表

**摘要中可提取的证据**：

| 内容 | 证据来源 | 提取方式 |
|------|----------|----------|
| 完整标题 | 摘要"试验标题"部分 | R |
| 短标题 | 摘要"短标题" | R |
| 试验分期 | 摘要中的"I/II/III 期" | R |
| 适应症/人群诊断 | 标题或目的中的疾病描述 | R+L |
| 干预药物及剂量 | "试验干预"部分 | R+L |
| 设计类型（平行组/交叉等） | "试验设计"部分 | R |
| 盲法 | "双盲/单盲/开放" | R |
| 对照类型 | "安慰剂/阳性对照" | R |
| 样本量 | "计划入组" | R |
| 治疗持续时间 | "治疗期 X 周" | R |
| 主要/次要目的 | "试验目的"部分 | L |
| 估计目标简述 | 主要目的 + 终点 + 人群 | L |

**缺失时需交互补充**：
- 如果没有短标题，问："请提供一个适合临床试验注册中心使用的简短标题"
- 如果没有示意图描述，问："请描述试验各阶段的顺序和时长"
- 如果没有 SoA，问："请提供每次访视需要完成的评估"

### 第 2 章：引言

**本章定位**：解释为什么做这个试验，科学依据和获益风险评估。

**M11 要求内容**：
- 2.1 试验目的
- 2.2 获益和风险评估
  - 2.2.1 风险总结和缓解策略
  - 2.2.2 获益总结
  - 2.2.3 总体获益-风险评估

**摘要中可提取的证据**：

| 内容 | 证据来源 | 提取方式 |
|------|----------|----------|
| 试验目的（高层次） | 摘要"试验目的" | L |
| 疾病背景（少量） | 摘要开头的背景描述 | L |
| 已知风险/安全性考虑 | "安全性评估"或"排除标准"中隐含 | L |
| 获益假设 | 主要目的和终点中隐含 | L |

**摘要中通常不足、需要 IB/文献补充的**：
- 疾病流行病学和自然病程
- 当前标准治疗
- 药物作用机制
- 非临床和既往临床安全性数据
- 详细的风险缓解策略

**缺失时需交互补充**：
- "请提供研究者手册（IB）或药物作用机制描述"
- "请描述该适应症当前未满足的医学需求"
- "请列出本试验需要特别关注的已知风险"

### 第 3 章：试验目的和相关估计目标

**本章定位**：精确定义每个试验目的和估计目标。

**M11 要求内容**：
- 3.1 主要目的和相关估计目标
- 3.2 次要目的和相关估计目标
- 3.3 探索性目的

**摘要中可提取的证据**：

| 内容 | 证据来源 | 提取方式 |
|------|----------|----------|
| 主要目的描述 | "主要目的" | R+L |
| 主要终点 | "主要终点" | R+L |
| 次要目的描述 | "次要目的" | R+L |
| 次要终点 | "次要终点"列表 | R+L |
| 探索性目的 | "探索性目的" | L |
| 目标人群特征 | 入排标准 + 适应症 | L |
| 治疗条件 | 干预方案 | R+L |
| 伴发事件策略 | 设计中隐含（停药、补救治疗等） | L |
| 群体水平汇总 | 统计方法中隐含 | L |

**估计目标五属性（ICH E9(R1)）**：
- 人群：从入排标准提取
- 治疗：从干预方案提取
- 终点：从终点定义提取
- 伴发事件：从设计、终止规则提取
- 群体水平汇总：从统计方法提取

**提取方式**：L（需要 LLM 综合多个 section 理解）

**缺失时需交互补充**：
- "请确认主要目的对应的治疗效应是什么？"
- "请描述主要伴发事件的处理策略（如停药、补救治疗等）"
- "主要估计目标的群体水平汇总是什么？（如差值、比值、风险差等）"

### 第 4 章：试验设计

**本章定位**：详细描述试验如何开展，以及为什么这么设计。

**M11 要求内容**：
- 4.1 试验设计描述
- 4.2 试验设计依据
- 4.3 试验停止规则
- 4.4 试验开始和结束
- 4.5 试验结束后获得试验干预

**摘要中可提取的证据**：

| 内容 | 证据来源 | 提取方式 |
|------|----------|----------|
| 设计模式（平行组/交叉/析因） | "试验设计"部分 | R |
| 干预模式 | 干预方案 + 设计描述 | R+L |
| 对照类型及选择 | "试验设计"部分 | R |
| 随机化方法 | 随机化描述 | R+L |
| 分层因素 | "按 XX 分层" | R |
| 盲法及揭盲规则 | "双盲"等描述 | R+L |
| 试验持续时间 | 筛选期/治疗期/随访期 | R |
| 治疗期各阶段 | 示意图描述 | L |
| 适应性设计特征 | 如果有 | L |
| 期中分析 | 统计考虑中 | L |

**设计依据（4.2 节）**：
- 通常摘要不会详细说明
- 可以从目的、终点、对照选择中部分推断
- 需要 LLM 基于医学常识补充

**缺失时需交互补充**：
- "请选择随机化方法（简单随机化/区组随机化/分层随机化）"
- "请说明选择安慰剂对照/阳性对照的依据"
- "是否有计划进行期中分析？"
- "是否有数据监查委员会（DMC）？"

## 三、摘要证据提取优先级

### 高优先级（必须准确提取，否则影响全文质量）

1. **试验标题、分期、适应症**
2. **主要目的和主要终点**
3. **设计类型、盲法、对照、随机化**
4. **样本量**
5. **干预药物、剂量、给药途径**
6. **年龄范围、关键入排标准**
7. **治疗持续时间**

### 中优先级（支撑各章扩写，但缺失可交互补充）

1. 次要目的和次要终点
2. 给药频率和治疗方案细节
3. 安全性评估项目
4. 统计分析方法
5. 伦理和 DMC 信息

### 低优先级（摘要中通常不完整，需外部资料或 LLM 推断）

1. 详细的设计依据
2. 剂量选择依据
3. 风险缓解策略
4. 停药/退出规则
5. 药物制备储存条件

## 五、缺失信息交互清单

以下是根据摘要提取后，可能需要弹窗交互补充的常见问题：

### 基本信息
- 短标题是什么？
- 试验是否有特定缩写或代号？
- 申办者名称和地址？

### 设计
- 随机化方法是什么？（简单/区组/分层）
- 分层因素是什么？
- 是否计划期中分析？
- 是否有数据监查委员会？

### 人群
- 是否有避孕要求？
- 是否有生活方式限制？
- 筛选失败后是否允许重新筛选？

### 干预
- 药物的剂型和规格？
- 储存条件？
- 剂量调整规则？
- 是否有允许/禁止的合并用药？

### 评估
- 每次访视的具体评估项目？
- PK/生物标志物/免疫原性采样时间点？

### 统计
- 分析集定义？
- 样本量计算详细依据？
- 多重性调整策略？

### 安全
- 是否有特别关注的不良事件？
- 是否有已知的严重风险？

## 六、对 LLM 生成的支撑方式

### 6.1 直接证据支撑

对于摘要中明确包含的信息，直接作为 prompt 中的事实：

```markdown
## 已知事实
- 主要终点：第 16 周 PASI 75 应答率
- 样本量：180 例
- 设计：随机、双盲、安慰剂对照、平行组
```

### 6.2 原文片段支撑

对于需要保留医学表述的内容，提供原文片段：

```markdown
## 摘要原文（入选标准）
- 签署知情同意书时年龄 ≥ 18 周岁且 ≤ 75 周岁
- 诊断为斑块型银屑病 ≥ 6 个月
- 基线 PASI 评分 ≥ 12 分
```

### 6.3 推理提示支撑

对于摘要中没有但可推断的内容，给 LLM 明确的推理指令：

```markdown
## 推理任务
基于以上入排标准，撰写第 5.1 节"试验人群描述和依据"。
要求：说明目标人群为中重度斑块型银屑病患者，并解释入排标准选择的依据。
```

### 6.4 缺失标记支撑

对于确实没有信息的内容，明确要求 LLM 保留占位符：

```markdown
## 缺失信息
- 药物储存条件：<输入储存条件>
- 剂量调整规则：<输入剂量调整规则>
```

## 七、总结

### 摘要能支撑什么？

- ✅ 全文 60-70% 的结构性内容
- ✅ 所有关键事实（目的、设计、人群、干预、终点、统计）
- ✅ 各章节的写作方向和基本框架

### 摘要不能支撑什么？

- ❌ 详细的医学背景（需 IB/文献）
- ❌ 设计依据和剂量依据（需专业知识）
- ❌ 详细的运营流程（需 SOP/公司规范）
- ❌ 完整的附录内容（需外部资料）

### 产品启示

1. **不要期望摘要生成完美方案**，初稿目标现实
2. **交互补充是关键能力**，决定生成质量上限
3. **证据 Section 化比纯元数据更有用**，能支撑 LLM 基于原文扩写
4. **不同章节对证据的依赖不同**，要为每个 Skill 声明需要哪些证据 Section
5. **保留占位符是安全策略**，不确定的内容不要编造
