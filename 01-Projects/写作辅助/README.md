# 写作辅助（方案撰写）

主线项目：用 AI 辅助 ICH M11 方案撰写，覆盖竞品分析、摘要元数据抽取和初稿生成。

## 目录

```text
写作辅助/
├── 笔记/          自己写的要点
├── 参考资料/      M11 官方 PDF
├── 工具/          从 synopsis 抽元数据的脚本
└── 样例/          摘要原文和抽取结果
```

## 笔记

- [[研发假设]]：研发假设怎么写、要判断什么。
- [[AI方案撰写_竞品分析与架构]]：竞品框架、差异化定位和 MVP 架构。
- [[M11文件总结]]：M11 十四章关系与撰写要点。
- [[项目决策记录]]：输入/输出/流程/交互等已定决策与待决事项。
- [[摘要证据映射分析]]：摘要能撑哪些章节、证据类型与提取方式。
- `笔记/m11_evidence_mindmap.html`：十四章证据支撑脑图（浏览器打开）。

## 参考资料

- `参考资料/M11指导原则中文版.pdf`
- `参考资料/M11模板中文版.pdf`
- `参考资料/M11-十四章节关系与撰写流程.pdf`

## 工具与样例

- `工具/metadata_extractor.py` + `工具/metadata_schema.yaml`
- `样例/synopsis_*.txt` → `样例/output_*.json`

## 飞轮

每写完一份方案或抽完一份摘要：把改对的字段回灌 schema/样例，改错的记进 [[可复用资产索引]] 的反例，并在 [[产出台账]] 加一行。下次先跑旧样例和 schema，再生成新稿。
