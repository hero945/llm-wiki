# 华东医药研发管线管理系统业务蓝图

## 1. 背景与目标

华东医药 PM 当前通过 Excel 管理多个药物研发管线。Excel 模板已经承载了管线配置、管线总览、Study台账、团队职责、风险管理、里程碑和职能进展，但存在以下问题：

- 数据分散在多个 sheet 中，跨项目汇总依赖人工维护。
- Project 状态与 Study 明细容易不一致。
- 用户权限、账号状态、操作责任无法系统化追溯。
- 风险、里程碑、团队和进展记录缺少统一的数据结构。
- 导入导出、批量维护和历史追溯需要更稳定的机制。

一期系统目标是将现有 Excel 工作方式系统化，降低业务迁移成本，同时为后续报表、提醒、审批和更细粒度治理预留结构。

## 2. 业务对象层级

系统核心层级为：

```text
Program -> Project -> Study
```

- **Program**：化合物或产品层级，例如某个产品名对应一个 Program。
- **Project**：化合物 + 适应症层级，一个 Project 对应一个适应症。
- **Study**：化合物 + 适应症 + 临床试验层级，是阶段状态、团队协作、风险和进展管理的重要承载对象。

## 3. 一期功能范围

### 3.1 管线配置

由超级管理员维护管线基础配置，包括 Source、Origin、Product、MOA、Program、Indication、Project、TA 等。业务方在创建或维护管线数据时优先从配置项中选择，减少自由文本带来的不一致。

### 3.2 管线总览

首页展示 Project 粒度的管线总览，字段包括 Source、Origin、Product、MOA、Program、Indication、Project、TA、研发阶段和 Approval Date。

总览状态由 Study 台账自动汇总，避免 PM 在 Project 和 Study 两处重复维护状态。

### 3.3 Study台账

Study台账是临床研究明细和阶段状态的数据源。系统应支持按项目、适应症、阶段、状态、负责人等维度查询和维护 Study。

Study 状态变化后，系统自动更新相关 Project 的阶段展示。

### 3.4 Team

Team 模块维护 Study 或 Project 相关团队职责，包括 PL、APL、PM、APM、RA、CM、CP、PV、TM、CO、Lab、Supply、ST、PG、DM、MW 等角色。

业务目标是让每个项目/研究的责任人可查询、可维护、可追溯。

### 3.5 Risk

Risk 模块用于临床试验项目层面的风险管理，保留 Excel 中的评分逻辑：

```text
风险总分 = 影响评分 * 可能性评分 * 可检测性评分
```

每条风险需要记录风险描述、风险归属、现有控制措施、额外控制措施、负责人、完成日期、再评估原因和评估后行动。

### 3.6 Timeline

Timeline 模块承接 Excel 中的里程碑模板，支持计划版本、实际开始、实际结束和延期/提前说明。

一期需要支持按阶段维护 Pre-IND、IND、Pre-3、Protocol、Site、FPI、LPI、DBL、CSR、NDA/BLA 等里程碑。

### 3.7 Progress

Progress 模块用于职能进展汇报，按周期记录 CM、CP、PV、CO、Lab、Supply、ST、PG、DM、MW、RA、CMC、Non-clinical 等职能的进展。

系统应保留类似 Excel 的二维录入体验：左侧为职能，右侧为指定周期的进展内容。

### 3.8 用户管理

系统登录账号由系统自管，不接入公司统一用户体系。

一期用户管理支持：

- 创建、编辑、停用用户。
- 分配角色和模块权限。
- 密码初始化和重置。
- 密码复杂度和有效期策略。
- MFA 多因素认证配置和状态查看。
- 最近登录时间和账号状态查看。

### 3.9 操作日志

系统记录关键操作日志，用于审计和问题追溯。

一期记录范围包括：

- 登录成功和失败。
- 新增、编辑、删除关键业务数据。
- 导入和导出。
- 用户、角色、权限变更。
- 密码重置、MFA启用或停用。

普通页面查看、筛选、排序不纳入一期日志范围。

## 4. 用户与角色

- **超级管理员**：维护字典配置、用户、角色、权限、系统策略。
- **PM**：维护 Program、Project、Study、Timeline、整体进展和项目级信息。
- **职能用户**：维护自己负责模块或职能的 Team、Risk、Progress 内容。
- **只读用户**：查看管线总览、Project详情、Study、风险和进展，不可编辑。

## 5. 核心页面

### 5.1 登录页

用户使用系统账号和密码登录。若账号启用 MFA，登录时需要完成第二因素验证。停用账号不可登录。

### 5.2 管线总览页

默认首页，以表格形式展示 Project 列表。支持筛选、排序、列配置、导出和进入 Project 详情。

### 5.3 Project详情页

Project详情页聚合展示该 Project 下的 Study、Team、Risk、Timeline 和 Progress，使用页签切换。

### 5.4 Study台账页

以表格方式管理 Study 明细，支持批量编辑、导入、导出和状态维护。

### 5.5 风险管理页

展示风险列表，自动计算风险总分，支持按项目、Study、负责人、状态和风险分值筛选。

### 5.6 用户管理页

支持管理员维护用户账号、角色、状态、MFA状态和密码策略相关操作。

### 5.7 操作日志页

支持按时间、用户、模块、对象、操作类型、结果状态筛选日志，并支持导出。

## 6. 业务验收标准

- Excel 模板中的关键 sheet 均能在系统中找到对应模块或明确的一期不做说明。
- 业务方可以通过管线总览快速查看 Project 状态。
- PM 维护 Study 后，Project 总览状态自动变化。
- 风险总分计算结果与 Excel 规则一致。
- 管理员可以创建用户、停用用户、分配角色并查看 MFA 状态。
- 关键数据变更和权限调整可以在操作日志中追溯。
