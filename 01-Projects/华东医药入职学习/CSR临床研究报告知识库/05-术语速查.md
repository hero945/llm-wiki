# 术语速查

## 核心文件和报告

| 缩写/术语 | 全称 | 中文 | 简要解释 |
|---|---|---|---|
| CSR | Clinical Study Report | 临床研究报告 | 单项临床研究的正式完整报告，用于监管审评、注册申报和内部决策 |
| Protocol | Clinical Trial Protocol | 临床试验方案 | 试验开始前规定怎么做，包括目的、设计、人群、终点、访视和安全监测 |
| SAP | Statistical Analysis Plan | 统计分析计划 | 详细规定如何分析数据，包括分析集、终点算法、缺失值处理和敏感性分析 |
| TFL | Tables, Figures, Listings | 表、图、列表 | 统计分析输出，是 CSR 结果章节的重要来源 |
| IB | Investigator's Brochure | 研究者手册 | 给研究者提供试验药物已有非临床和临床信息的文件 |
| ICF | Informed Consent Form | 知情同意书 | 受试者参加试验前需要理解和签署的文件 |

## 数据采集和系统

| 缩写/术语 | 全称 | 中文 | 简要解释 |
|---|---|---|---|
| CRF | Case Report Form | 病例报告表 | 用于收集临床试验数据的表单 |
| eCRF | Electronic Case Report Form | 电子病例报告表 | CRF 的电子版本，通常在 EDC 系统中填写 |
| EDC | Electronic Data Capture | 电子数据采集系统 | 临床试验数据录入、管理和清理的系统 |
| Query | Data Query | 数据质疑/疑问 | 数据管理发现缺失、异常或不一致后发给研究中心确认的问题 |
| Source Document | Source Document | 源文件 | 原始医疗记录或原始数据来源，例如病历、实验室报告、影像报告 |
| DBL | Database Lock | 数据库锁定 | 确认临床数据库清理完成并冻结，用于正式统计分析 |

## 安全性

| 缩写/术语 | 全称 | 中文 | 简要解释 |
|---|---|---|---|
| AE | Adverse Event | 不良事件 | 试验期间发生的任何不利医学事件，不一定和试验药物相关 |
| SAE | Serious Adverse Event | 严重不良事件 | 导致死亡、危及生命、住院、残疾等严重后果的不良事件 |
| AESI | Adverse Event of Special Interest | 特别关注不良事件 | 由于药物机制或已知风险，需要特别监测和汇总的不良事件 |
| SUSAR | Suspected Unexpected Serious Adverse Reaction | 可疑且非预期严重不良反应 | 可能与药物相关、严重且非预期的不良反应，通常有快速上报要求 |
| MedDRA | Medical Dictionary for Regulatory Activities | 医学监管活动词典 | 用于标准化不良事件和医学术语 |
| WHODrug | WHO Drug Dictionary | WHO 药物词典 | 用于标准化合并用药名称 |

## 数据标准和分析

| 缩写/术语 | 全称 | 中文 | 简要解释 |
|---|---|---|---|
| CDISC | Clinical Data Interchange Standards Consortium | 临床数据交换标准协会 | 临床研究数据标准体系 |
| CDASH | Clinical Data Acquisition Standards Harmonization | 临床数据采集标准 | 指导 CRF/eCRF 数据采集字段设计 |
| SDTM | Study Data Tabulation Model | 研究数据制表模型 | 用于提交和组织临床试验观察数据的标准 |
| ADaM | Analysis Data Model | 分析数据模型 | 用于统计分析的数据集标准 |
| Define-XML | Define-XML | 数据定义文件 | 描述提交数据集结构、变量和来源的机器可读文件 |
| Analysis Set | Analysis Set | 分析集 | 统计分析使用的受试者集合，例如 FAS、PPS、SS |

## 角色

| 角色 | 中文 | 主要职责 |
|---|---|---|
| Clinical Lead | 临床负责人 | 定义临床问题、人群、终点，并解释医学意义 |
| Statistician | 统计师 | 设计样本量、分析方法、SAP，并解释统计结果 |
| Programmer | 统计程序员 | 生成分析数据集和 TFL |
| Medical Writer | 医学写作 | 整合 protocol、SAP、TFL 和医学解释，起草 CSR |
| Data Manager | 数据管理 | 设计数据采集、清理数据库、管理 query 和锁库 |
| CRA | Clinical Research Associate，临床监查员 | 监查中心执行、数据质量和 GCP 合规 |
| CRC | Clinical Research Coordinator，临床研究协调员 | 协助研究中心执行访视、资料收集和 eCRF 录入 |
| PI | Principal Investigator，主要研究者 | 在研究中心负责试验执行和受试者安全 |
| PV/Safety | 药物警戒/安全团队 | 管理 AE/SAE、安全报告、风险评估和监管上报 |
| QA | Quality Assurance，质量保证 | 确保流程、文件和系统符合质量与合规要求 |

## 常用流程缩写

| 缩写 | 全称 | 中文 | 说明 |
|---|---|---|---|
| IND | Investigational New Drug | 新药临床试验申请 | 在部分国家/地区用于申请开展临床试验 |
| CTA | Clinical Trial Application | 临床试验申请 | 临床试验启动前向监管机构提交的申请 |
| FPI | First Patient In | 首例受试者入组 | 第一位受试者进入试验 |
| LPI | Last Patient In | 末例受试者入组 | 最后一位受试者进入试验 |
| LPLV | Last Patient Last Visit | 末例受试者末次访视 | 数据收集进入收尾阶段的重要节点 |
| DMC/IDMC | Data Monitoring Committee / Independent Data Monitoring Committee | 数据监查委员会/独立数据监查委员会 | 独立评估试验数据和安全风险的委员会 |
| TMF | Trial Master File | 试验主文件 | 保存临床试验关键文件的档案体系 |
