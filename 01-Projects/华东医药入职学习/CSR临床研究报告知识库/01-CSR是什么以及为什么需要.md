# CSR 是什么以及为什么需要

CSR 是 Clinical Study Report 的缩写，中文通常叫**临床研究报告**。

在临床试验、新药研发、适应症扩展和医学写作语境下，CSR 是对一项临床研究的正式、完整、可审查总结。它通常按照监管和公司模板组织，说明这项研究为什么做、怎么做、实际招了哪些人、数据结果是什么、安全性如何，以及这些结果支持什么结论。

## CSR 的定位

可以把 CSR 理解为一项临床试验的“正式证据包正文”。

它不是单纯的论文，也不是简单的数据报表，而是把这些内容组织到一起：

- 研究背景和目的
- 研究设计和执行过程
- 受试者入组、完成和退出情况
- 疗效结果
- 安全性结果
- 统计方法和分析结果
- 方案偏离和研究限制
- 医学解释和结论
- 表、图、列表及附录

## 为什么需要 CSR

### 1. 给监管机构审评

新药上市申请、适应症扩展、剂量调整或关键补充资料，通常都需要监管机构理解单项研究的证据。CSR 是审评人员判断研究可信度和结果意义的重要材料。

### 2. 证明试验是怎么做的

CSR 不只写结果，还要说明：

- protocol 是如何设计的
- 入排标准是什么
- 受试者如何分组和给药
- 主要终点和次要终点是什么
- 统计方法是否事先规定
- 试验过程中有没有方案偏离、修订或特殊情况

换句话说，CSR 要回答：**这个结果是怎么来的，是否值得相信。**

### 3. 系统呈现疗效和安全性

一项临床试验会产生大量数据。CSR 把分散数据整理成医学和监管可以理解的叙述，包括疗效、安全性、暴露、实验室检查、不良事件、死亡、严重不良事件等。

### 4. 保证可追溯和合规

CSR 通常要能追溯到上游材料：

- Protocol（临床试验方案）
- SAP（统计分析计划）
- CRF/eCRF（病例报告表/电子病例报告表）
- 数据库和标准化数据集
- TFL（Tables, Figures, Listings，表、图、列表）

如果 CSR 中说某个结论成立，审阅者需要能追溯到对应数据和分析。

### 5. 支持后续决策和医学沟通

CSR 还会被用于：

- 注册申报资料
- 临床总结和获益风险评估
- 后续研究设计
- 论文和摘要撰写
- 内部研发决策
- 合作方或监管沟通

## 和字段的关系

如果一个文件里有 CSR 相关字段，可以这样理解：

**CSR 是完整报告，字段是报告中可以被结构化记录、抽取、生成或校验的信息单元。**

例如：

| 字段类型 | 例子 | 对应 CSR 内容 |
|---|---|---|
| 基本信息 | 研究编号、申办方、适应症、药物名称 | 封面、摘要、研究概述 |
| 设计信息 | 随机、盲法、治疗组、样本量 | 研究设计章节 |
| 终点信息 | 主要终点、次要终点 | 研究目的和统计分析 |
| 受试者信息 | 入组、完成、退出、分析集 | 受试者处置和基线特征 |
| 结果信息 | 疗效结果、不良事件、实验室异常 | 结果和安全性章节 |
| 审核信息 | 数据来源、CSR 章节、核对状态 | 质量控制和追溯 |
