# 05-Templates

这里存放 Obsidian 常用模板。新建项目、学习笔记、周复盘和领域首页时，从这里复制结构。

## 模板列表

- [[学习项目模板]]
- [[学习笔记模板]]
- [[每周复盘模板]]
- [[领域首页模板]]
- [[交付物沉淀卡片]]：一份工作交出去之后，拆决策/样例/术语/反例并登记台账

## 使用建议

- 有目标、有截止日期的学习任务，用 [[学习项目模板]]。
- 读文章、看课程、整理概念，用 [[学习笔记模板]]。
- 每周五或周日整理一次，用 [[每周复盘模板]]。
- 给长期主题建导航页，用 [[领域首页模板]]。
- 工作交付完成后，用 [[交付物沉淀卡片]]，并登记 [[产出台账]]。
